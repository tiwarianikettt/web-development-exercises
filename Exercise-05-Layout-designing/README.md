# Exercise 05 - Layout Designing

## 📌 Topic

CSS Layout Designing

## 🎯 Objective

Recreate the given reference layout using HTML and CSS.

The exercise focuses on building a webpage layout by combining different CSS concepts learned so far, including Flexbox, Positioning, Sticky Navigation, Fixed Positioning, Border Radius, and Box Model.

## 💡 What I Learned

- Designing a webpage by dividing it into multiple sections.
- Using **Flexbox** to align multiple containers horizontally.
- Understanding the difference between **Sticky** and **Fixed** positioning.
- Creating a floating action button using `position: fixed`.
- Making a navigation bar remain visible while scrolling using `position: sticky`.
- Using `z-index` to control the stacking order of overlapping elements.
- Creating rounded containers using `border-radius`.
- Using margins and padding to create spacing between sections.
- Understanding that block-level elements occupy the available width by default.
