# Exercise 1 - Multimedia Website

## 📖 Objective

Create a webpage using **HTML only** that displays and plays **5 audio files** and **5 video files**.

## 🛠️ Technologies Used

- HTML5

## 📚 Concepts Practiced

- Basic HTML Structure
- Headings (`<h1>`, `<h2>`)
- `<audio>` Element
- `<video>` Element
- `<source>` Element
- HTML Attributes (`controls`, `loop`, `muted`, `autoplay`, `width`)
- Organizing media files using folders

## 📁 Project Structure

```
Exercise-01-Multimedia-Website/
│
├── index.html
├── README.md
├── audios/
│   ├── 1.mp3
│   ├── 2.mp3
│   ├── 3.mp3
│   ├── 4.mp3
│   └── 5.mp3
│
└── videos/
    ├── 1.mp4
    ├── 2.mp4
    ├── 3.mp4
    ├── 4.mp4
    └── 5.mp4
```

## 🎯 Learning Outcome

This exercise helped me understand how to embed multimedia content in HTML using the `<audio>` and `<video>` elements, organize project files, and build a simple webpage without using CSS or JavaScript.
