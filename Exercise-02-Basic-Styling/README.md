# Exercise 2 - Basic CSS Styling

## 📖 Objective

Create a webpage containing five paragraphs inside a `div`. Apply the following styles:

- The **first paragraph** should have:
  - Yellow background
  - Red text
- The **remaining paragraphs** should have:
  - Blue background
  - White text

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 Concepts Practiced

- External CSS
- Element Selector
- Pseudo-class Selector (`:first-child`)
- CSS Colors
- CSS Specificity

## 📁 Project Structure

```text
Exercise-02-Basic-Styling/
│
├── index.html
├── style.css
└── README.md
```

## 🎯 Learning Outcome

This exercise helped me understand how to apply CSS styles using selectors and pseudo-classes. I learned how to style the first child of a parent element without adding extra classes or IDs, making the code cleaner and more efficient.
