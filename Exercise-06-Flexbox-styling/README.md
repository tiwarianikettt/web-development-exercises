# Exercise 06 - UltraEdit Navbar Clone

## 📌 Objective

The objective of this exercise was to recreate the navigation bar of the **UltraEdit** website using **CSS Flexbox**.

This exercise focuses on understanding how Flexbox can be used to create responsive and well-aligned navigation layouts similar to real-world websites.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- Font Awesome Icons

---

## 📚 Concepts Practiced

- CSS Flexbox
- Horizontal Navigation Bar
- justify-content
- align-items
- gap
- CSS Box Model
- Buttons & Icons
- Links Styling
- Border Radius
- Layout Structuring
