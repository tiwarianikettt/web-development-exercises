# Exercise 4 - CSS Variables Navigation Bar

## 📖 Objective

Create a multi-color website that includes a navigation bar using CSS Variables (Custom Properties).

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 Concepts Practiced

- CSS Variables (Custom Properties)
- `:root` Selector
- `var()` Function
- Flexbox
- Navigation Bar Styling
- Hover Effects
- CSS Transitions

## 📁 Project Structure

```text
Exercise-04-CSS-Variables/
│
├── index.html
├── style.css
└── README.md
```

## 🎯 Learning Outcome

This exercise helped me understand how to declare and use CSS Variables to create reusable styles. I also learned how to build a navigation bar using Flexbox while improving code maintainability by replacing repeated values with reusable CSS variables.
