# Exercise 07 - CSS Grid

## 📌 Topic
CSS Grid

## 🎯 Objective

Recreate the older version of the **UltraEdit Download Page** using **CSS Grid**.

This exercise focuses on understanding how CSS Grid can be used to create structured, responsive layouts by arranging multiple cards in rows and columns.

> **Note:**  
> The official UltraEdit website has been redesigned since this exercise was created. Therefore, this project intentionally recreates the older version shown in the **CodeWithHarry Sigma Web Development Course**.

A reference image of the original layout is included in the **images** folder.

## 💡 What I Learned

- Creating layouts using CSS Grid.
- Understanding the difference between Grid and Flexbox.
- Arranging multiple cards using rows and columns.
- Using `repeat()` and `fr` units to create flexible layouts.
- Using `gap` for consistent spacing between grid items.
- Letting the Grid container control the layout instead of assigning fixed widths to individual cards.
- Combining Grid for page layout and Flexbox for aligning content inside cards.
